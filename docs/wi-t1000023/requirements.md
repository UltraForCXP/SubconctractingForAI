## 4. 角色与业务场景

### 4.1 业务角色

- **供应链系统/核销经办人**：在委外核销调整界面执行“调整”，生成记录调整差额的核销调整记录。
- **财务（信控/存货核算）**：使用释放后的供应商可用额度，并核对信用流水与核销结果。
- **系统联动能力**：自动生成、提交并审核释放单，不增加人工审批节点。

### 4.2 主流程

1. 业务人员在委外核销调整界面执行「调整」，生成委外采购核销调整记录，记录本次调整差额。
2. 调整完成后触发 KingScript，读取调整记录及其关联入库单、委外采购订单和原信用占用信息。
3. 脚本按第 5.2 节公式确定释放值，并保证供应商、控制组织、币别和原占用口径一致。
4. 脚本调用苍穹 API，按 BOTP 生成规则创建「委外损耗信用释放单」；BOTP 保存核销调整记录编号的源单关联。
5. 创建成功后自动提交并审核，不走审批流。
6. 审核时生成方向为“释放”的信用流水，按供应商＋控制组织回加可用额度。
7. 业务人员可从释放单追溯核销调整记录，并核对释放金额/数量、币别和信用流水。

### 4.3 边界与异常原则

- 本需求只覆盖蓝图所述“损耗调增至实际消耗量”后的剩余授信释放，不扩展到其他核销差异类型。
- 创建、提交、审核和信用流水是同一业务链路的不同状态；只有审核并产生信用释放流水，才可认定本次授信释放完成。
- 用户确认不存在撤销核销调整场景，不设计撤销联动。
- 重复触发、接口超时和部分失败的处理未见蓝图规定，列为第 7 节专家建议，不作为已确认业务政策。

## 5. 业务与实施定义

### 5.1 新增单据结构

单据名称为「委外损耗信用释放单」，无单据体，仅单据头业务字段。归属为信用控制管理应用下新建的“授信管理”功能分组。

| 业务字段 | 类型/引用 | 来源与取值 | 业务规则 |
| --- | --- | --- | --- |
| 供应商 | 供应商基础资料引用，目标类型 `bd_supplier` | 核销调整记录关联委外采购入库单的供应商 | 与原信用占用维度一致 |
| 释放金额 | 数值/金额 | 金额控制时：调整差额数量×关联委外采购订单加工费单价；数量控制时：调整差额数量 | 同一字段承载两种控制维度的本次释放值；精度与舍入沿用平台及信用流水口径，材料未要求新增舍入规则 |
| 币别 | 币别基础资料引用 | 随原信用占用流水币别携带，可参考核销调整记录/对应委外采购订单币别 | 必须与原占用、释放流水同币别；准确引用编码待在线核实 |

通用字段沿用单据标准能力：单据编号、组织、日期、状态、制单人、审核人，不额外设计自定义字段。业务/记账日期取核销调整记录记账日期，期间保持一致且大于等于当前期间。源单关联由 BOTP 标准源单携带机制生成，不另建文本字段替代关联。

### 5.2 释放计算口径

| 授信控制维度 | 释放值公式 | 单位/币别要求 |
| --- | --- | --- |
| 金额 | `释放金额 = 调整差额数量 × 关联委外采购订单加工费单价` | 与原信用占用流水同币别、同加工费单价口径；不得使用“单价默认 1” |
| 数量 | `释放金额字段的释放值 = 调整差额数量` | 与原数量占用口径一致，不再乘加工费单价 |

“调整差额数量”直接取本次核销调整记录记录的差额。蓝图损耗示例为调增至实际消耗量：发料 10 吨、入库 9 吨、调增 1 吨至 10 吨，本次释放差额为 1 吨；金额控制时若订单加工费单价为 `P`，本次释放金额为 `1×P`。

### 5.3 BOTP 数据携带与源单关联

BOTP 源单为 `cal_omwfadjustrecord`，目标单为本次新增「委外损耗信用释放单」。源、目标均为单据头数据，不建立分录映射。

| 释放单信息 | 来源/规则 | 业务说明 |
| --- | --- | --- |
| 供应商 | 核销调整记录关联入库单的供应商 | 保持授信维度一致 |
| 释放金额 | 按第 5.2 节统一公式计算的释放值 | 跨入库单、订单取数由 KingScript 准备；BOTP 负责目标字段映射 |
| 币别 | 原占用流水币别；核销调整记录/对应订单币别用于核对 | 保证同币别对冲 |
| 业务/记账日期 | 核销调整记录记账日期 | 保持期间一致，大于等于当前期间 |
| 源单编号及源单关联 | 核销调整记录编号 | 使用生成规则标准源单机制，支持追溯 |

### 5.4 KingScript 与苍穹 API 联动职责

| 环节 | 要求 |
| --- | --- |
| 触发 | 业务人员在核销调整界面完成“调整”、生成核销调整记录后触发；实际插件事件沿该生成链路确认 |
| 数据准备 | 读取调整差额、关联入库单供应商、关联订单加工费单价、原占用币别及控制组织 |
| 计算 | 按金额或数量控制维度计算第 5.2 节释放值，不采用占位单价 |
| 创建 | 调用苍穹 API，按已配置 BOTP 生成规则创建释放单并保存标准源单关联 |
| 生命周期 | 创建成功后自动提交、自动审核，不走审批流 |
| 完成判定 | 以释放单审核并生成信用释放流水为完成；仅创建或提交成功不代表授信已释放 |

### 5.5 授信管理配置

| 配置项 | 要求 |
| --- | --- |
| 单据纳入 | 将「委外损耗信用释放单」纳入信用控制管理体系 |
| 方向 | 释放，审核后回加供应商可用额度 |
| 生效时点 | 单据审核 |
| 控制维度 | 供应商＋控制组织，与委外采购订单占用策略对称 |
| 授信方案 | 与委外采购订单占用、委外采购入库释放纳入同一方案对冲 |
| 信用流水 | 审核生成释放方向流水，释放值及币别符合第 5.2 节 |
| 前置数据 | 供应商已纳入统一授信管理，授信额度档案已维护额度值与币别；订单占用和入库释放规则可用 |
